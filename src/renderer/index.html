Endpoint

Endpoint OpenAI-compatible. Contoh: https://openrouter.ai/api/v1 (default), http://localhost:8080/v1 (9router self-hosted), atau http://localhost:11434/v1 (Ollama).

Disimpan terenkripsi via safeStorage OS. Untuk endpoint lokal tanpa autentikasi, isi apa saja (mis. none).
